# Published research model catalog

The binary adapter is a separate GitHub Release asset. This folder stores its configuration,
ordered vocabularies and the exact seven frozen algorithm sources. Paths in catalog.json
refer to the downloaded package root. See [the model guide](../../docs/MODEL_RELEASE_20261019.md).

The State-distilled adapter retains the [State non-commercial model license](../../licenses/MODEL_LICENSE.md).
Repository code licensing does not remove those weight restrictions. Round27 is not included.
